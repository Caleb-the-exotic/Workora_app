# Workora HRMS

Workora is a modern, high-performance Human Resource Management System (HRMS) designed for forward-thinking organisations. It provides end-to-end self-service portals for employees and comprehensive operations hubs for HR administrators.

## Features

- **Workora Admin & HR Console**:
  - **Overview Dashboard**: Realtime headcount, attendance breakdown, pending approvals, and payroll timelines.
  - **Employee Directory**: Filterable database of all staff with detailed profiles, job types, and direct actions.
  - **Attendance Management**: Daily & weekly attendance tracking, live punch-in/out timestamps, and exportable registers.
  - **Leave Approvals**: Review queue, balance deduction checks, attached certificates, and instant decision workflows with comments.
  - **Payroll Operations**: Salary structure management (Basic, HRA, statutory deductions), payroll cycle locking, and payslip generation.
  - **Reports & Analytics**: Interactive charts for attendance trends, leave utilization, headcount growth, and salary distributions.
  - **Notification Centre (`/hr/notifications`)**: Multi-category alert stream for approvals, leave, attendance anomalies, and payroll deadlines with mark-all-read.
  - **HR Settings (`/hr/settings`)**: Configurable organisation profile, statutory leave policies, payroll cut-offs, and alert preferences.

- **Workora Employee Portal**:
  - Personalized employee hub with live attendance punch cards, working hour calculations, and quick leave actions.
  - Interactive profile self-service with document repository and salary breakdown.
  - Leave requests with auto-calculated duration and balance tracking.
  - Notification centre and account preference controls.

- **Global UX Polish**:
  - Collapsible sidebar with compact navigation.
  - Interactive breadcrumb navigation across all views.
  - Destructive action confirmation dialogs.
  - Built-in Dark Mode / Light Mode toggle with instant theme switching.
  - Fully accessible tooltips, skeleton loading states, and keyboard focus states.

## Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```
